# Chapter 2 – Configure Users, Devices and Workspaces

The goal of this section is to modify existing users, license them for Webex Calling, do some user centric config work, add a workspace or common area phone and begin to make some simple test calls. For the sake of this lab, we will not be integrating with an AD platform or IDP for authentication, rather we will be manually setting up our users and leveraging the native authentication offered by Webex.
