# About this lab

In this lab, you will be working in a FedRAMP collaboration hub organization configuring Webex Calling for Government. You start by laying down a common foundation that every deployment requires—configuring locations, setting organizational parameters, establishing PSTN connectivity, assigning phone numbers, and licensing users. These steps ensure that your environment is fully prepared for the next phase. 

Once the baseline setup is complete, you’ll move into the more technical sections of this lab where you will build and test a variety of different features. Each feature highlights practical use cases and showcases how Webex Calling for Government can be adapted to solve real-world communication needs.

By the end of the lab, you will have hands-on experience not only with the core deployment process, but also with designing, implementing, and validating vertical-focused capabilities that make the solution impactful in real business environments.
